# Student Utility Website

A simple frontend website built to help students access academic information
like subjects, timetable, and important links from one place.

## Features
- Displays semester subjects
- Shows basic weekly timetable
- Provides quick access to important academic links

## Technologies Used
- HTML
- CSS

## What I Learned
- Structuring content using HTML
- Styling clean layouts using CSS
- Designing simple user-focused interfaces
